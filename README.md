# Точка контакта

Браузерная игра о поиске работы и людях — с двух сторон стола.

Соискатель устал от отказов, наниматель тонет в резюме. Одна история, две точки зрения и три финала: предложение, компромисс или честное «нет». В конце — разбор решений и ссылка на резюме автора.

**Играть:** откройте `index.html` или опубликуйте папку на GitHub Pages.

![Превью игры «Точка контакта»](preview.png)

## Что внутри

- Два режима: **Соискатель** и **Наниматель**.
- По шесть этапов в каждом: путь от резюме до предложения, а у нанимателя — ещё и первый месяц команды.
- Три финала для каждой стороны — результат зависит от решений, а не от одного «правильного» ответа.
- Вопросы и варианты ответов перемешиваются в каждом новом прохождении. Порядок нельзя заучить, а сохранение запоминает seed — при продолжении порядок остаётся тем же.
- Две мини-игры: сборка резюме из блоков и сортировка откликов. Блоки и кандидаты тоже перемешиваются.
- Дополнительные сложные вопросы: пробел в опыте, контроффер, внутренний кандидат и обратная связь отказанному кандидату.
- Показатели, которые меняются от выбора к выбору.
- Сохранение прогресса в `localStorage`, продолжение с того же этапа.
- Звук на WebAudio с возможностью отключить, конфетти и кнопка «Поделиться результатом».
- Нумерация этапов и вопросов, чтобы не терять место в истории.
- Цитаты поддержки в финале — для моментов, когда силы на нуле.
- Экран статистики: прохождения, средний и лучший результат, стороны, финалы, страны, города и топ-10.
- Десять достижений, мемы, секретный код и другие пасхалки.
- Адаптивная вёрстка, поддержка клавиатуры и `prefers-reduced-motion`.

## Управление

- Мышь или палец — выбор вариантов и кнопки.
- Клавиши **1–4** — быстрый выбор ответа в диалогах.
- **Esc** — закрыть диалог подтверждения.
- Кнопка с динамиком в шапке — включить или выключить звук.
- Кнопка с графиком в шапке — экран статистики и общий рейтинг.

Прогресс сохраняется автоматически. Если вернуться на главную, незаконченный путь можно продолжить по кнопке «Продолжить путь». При запуске новой игры поверх сохранения появится подтверждение.

## Локальный запуск

Игра не требует сборки и зависимостей — это один статический файл.

Можно просто открыть `index.html` в браузере. Для проверки «как на хостинге» удобнее поднять локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть <http://localhost:8000/>.


## Технические заметки

- Прогресс и seed перемешивания: `tochka.contact.save.v1`
- Лучшие результаты: `tochka.contact.meta.v1`
- Настройка звука: `tochka.contact.sound`
- Локальные прохождения: `tochka.contact.runs.v1`
- Анонимный ID игрока: `tochka.contact.player.v1`
- География: `tochka.contact.geo.v1`
- Достижения: `tochka.contact.achievements.v1`
- Оценка пути складывается из качества решений и среднего значения показателей; финал выбирается по порогам, а не по одному ответу.
- Без настроенного Supabase игра не отправляет данные на сервер: всё хранится локально в браузере. После настройки отправляется только обезличенная запись о прохождении (см. раздел выше).

## Дисклеймер
